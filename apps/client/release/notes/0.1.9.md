**Polestar Client 0.1.9** is code-signed on Windows, so Windows 11's Smart App Control lets it run.

Already have Polestar Client 0.1.4 or newer? Click **Update to 0.1.9** in the bar at the top of the window, and the app restarts on the new version. On 0.1.2 or older, look for it at the bottom of the sidebar (or in **Settings > About**).

## What's fixed

- **The Windows installer is now code-signed.** Polestar Client's installer and app now carry a code signature, so Windows 11's Smart App Control no longer blocks them, and Windows names the publisher instead of "Unknown publisher". If Smart App Control stopped an earlier version, download this one from **Assets** below and install it. Thanks Anthea for the report (#3397).

**First launch:**
- **Windows** may still say "Windows protected your PC" for a new version while Windows gets to know it. The installer is now code-signed, so it shows who published it: click **More info**, then **Run anyway**.
- **Mac:** the app is signed and checked by Apple; open the .dmg, drag Polestar Client into Applications, and open it.
- **Linux AppImage:** make it executable (right-click > Properties > Allow executing, or `chmod +x`), then run it.
