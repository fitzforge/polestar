# Skins for Polestar 0.3.8: renders

Feature Studio renders of the skins drawn in Polestar's own art (Polestar's
house look, Vellum, Lumen, Beacon, Aurora and Hearth), for the pull requests
that bring them. Each grid: the guide window on a step, a heads-up card over
it, the waypoint arrow, and the map's route and step pins.

Drawn from the addon's code with Polestar's and the skins' own art only: no
art of the game's, so the map has no terrain and the card's spell icon is a
placeholder. Each skin's layout preset is applied.
