- Polestar Client: Settings > About has Report a problem. Say what went wrong
  and read the report it writes: the client, system, game and addon versions,
  the status, the problems it shows and the recent failures. The account
  names, your user name, folder paths and tokens it finds are replaced, so
  read it before you send it. Copy it for the Polestar Discord's #bugs, or
  open it as a GitHub issue with the fields filled in. The client sends
  nothing itself (thanks mcclaskiem, who proposed it).
