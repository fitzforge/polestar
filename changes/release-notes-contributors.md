section: contributors

- Every release's GitHub notes end with a Contributors section that tags each
  GitHub login who contributed to that release, so GitHub lists them on it:
  `forge release notes` builds it for the range from the previous release tag
  (pull request authors, co-authors, reporters of the issues it closes and
  shipped ideas; never the maintainer or bots) and prints each login with why.
  A hotfix gets the same section from its picks.
