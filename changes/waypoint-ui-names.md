- With Waypoint UI installed and Options > Navigation > Blizzard waypoint on,
  its marker in the world now follows the guide by name: a quest objective or
  turn-in tracks the quest itself (Waypoint UI's own quest marker), and any
  other goal is a pin named after the step ("Talk to Executor Arren") instead
  of "Map Pin". Polestar only clears the pin or tracked quest it set, never one
  you chose. Without Waypoint UI nothing changes.
