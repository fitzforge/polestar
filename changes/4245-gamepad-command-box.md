- With the game's gamepad interface on, Polestar's commands have a place to
  be typed again: Run a command, in the minimap button's menu and on the
  Gamepad page of the settings, opens a small box of Polestar's own. Type
  `next`, `options` or `way 52 40`, with or without `/polestar` in front,
  and press Enter; Escape, or B on the gamepad, closes it. It works with the
  keyboard while the gamepad interface is on, and it never uses the game's
  chat box, which is why the slash commands stay off there (thanks
  NemesisTWarlock, #4245).
