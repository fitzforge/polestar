- In the Discord suggestions forum, the maintainer's `!suggest` inside a post
  files the whole post as one issue: the first message as the body and every
  reply as a comment in order, each with its author. The post is then followed
  like a #bugs post (new replies copied, "Tracked as #N" and the Tracked tag),
  and closes, pull requests, questions and releases are told in the post as an
  idea's ("This idea is planned", "This idea has shipped in Polestar X", "Not
  planned for now"). Set `SUGGESTIONS_FORUM_ID` on the bot and as a repository
  variable.
