- Rare alerts: a rare first seen without its name (one Polestar's lookup
  data doesn't have yet, such as Bjorn in Dun Morogh) no longer gets a Target
  button that tries to target "Unknown rare". The card takes the rare's name
  as soon as you see it again, Target included, and later alerts for it
  start with that name (#2254, thanks thmastin).
