- With the game's gamepad interface on, the game to play on a flight is
  offered again: Tetris, which plays with the gamepad (D-pad moves, A and B
  rotate, X drops, Y holds, Start pauses, RB closes it and gives the buttons
  back). Freedoom Arcade and Sky Jewels still need the keyboard and mouse. The
  Flight arcade setting no longer vanishes with the gamepad interface: a
  search for "arcade" finds it, its list shows only the games that play
  there, and its help says why. A saved choice of another game stays saved
  (#4245).
