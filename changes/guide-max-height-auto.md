- Guide window: a "Window height" option. Fixed keeps the window at the height
  you set, like any resizable window (a long step scrolls); Follows the step,
  the default, grows with the step up to it as before; Automatic uses all the
  free room on screen, less the class quest card. Set the height with its
  slider, by typing the pixels in the box beside it, or by dragging the grip
  up or down: it sits on the edge that moves (just over the top right with
  Grow upward), and a line with the pixels shows the height while you drag.
