- New Class guides for the Dungeon Set 2 (Tier 0.5) chain, one for every class
  on both sides, from An Earnest Proposition to Saving the Best for Last: what
  to buy before you start, where each sample, ghost and component drops, which
  dungeon and boss each part needs, the 45-minute Baron run, the summons, the
  costs, and the Argent Dawn reputation the Hallowed Brazier asks for. The
  dungeon and elite parts ask first, so a solo player can stop before them.
  They are listed under your class's optional class quests (thanks Swiftfyre
  for the idea).
