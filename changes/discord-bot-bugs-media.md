- The Discord bug bot copies every author's images and videos in a #bugs
  thread to the issue, not only the reporter's, as it does in the suggestions
  forum.
- In a suggestions post the maintainer's `!report` files the whole post as a
  bug, like `!suggest` does as an idea. `!bug <text>` by the maintainer is
  `!report <text>`; for anyone else it stays the plain `!bug` help.
