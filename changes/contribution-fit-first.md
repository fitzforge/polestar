- A feature now gets the maintainer's yes, no or later within three days of
  its pull request opening, before any review asks you for changes; a later
  names its release. CONTRIBUTING.md opens with what Polestar is and the
  rules ("Before you build a feature"): ideas start as an issue or a post in
  #suggestions on the Discord, and only the maintainer declines anyone's
  work. The pull request form asks for `Fixes #N` and whether it is a
  feature (#3634).
