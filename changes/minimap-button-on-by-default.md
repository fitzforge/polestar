- New players start with the Polestar button on the minimap: click it to show
  or hide the guide window, right-click it for a short menu, drag it around
  the minimap's edge. If you already play, the button stays as you had it;
  turn it on or off under Options, Map, Guide & quests, Minimap button.
  Minimap button collectors gather it like any other addon's button, and it
  now stays where they put it.
