- Polestar Studio (`/studio`, its own addon beside Polestar): write a guide
  in game in one window docked to the screen's right edge, the steps on the
  left and the step you pick on the right. The toolbar places waypoints,
  paths, areas, kills, quests, bosses and marks where you stand; the quest
  log, targets, nearby objects and position open as tabs in the same window.
  Live sync plays the draft in Polestar as you write it, and Export gives
  the guide's import string, which Polestar's Import page reads and Studio
  opens again to fork it.
