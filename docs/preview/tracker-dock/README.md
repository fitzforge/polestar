# Docked guide review renders

Generated from real addon Lua with `node tools/preview/tracker-dock.js`.
Each image shows UI scales **0.64, 1.0 and 1.5**, from left to right.
The tab-style images also exercise all four guide-tab placements.
These are preview renders, not in-game screenshots. Client-owned game textures
are omitted when unavailable to the renderer; no client artwork is redistributed.
